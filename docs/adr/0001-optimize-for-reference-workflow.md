# Optimize for the Reference Workflow

hyogen.ai's MVP will be judged by one excellent Reference Workflow for a solo/prosumer Creator making faceless factual explainer or news shorts, not by broad but shallow coverage of every content mode, provider, and workflow permutation. Fiction, promo, how-to, and alternative provider paths may exist where cheap, but they should not dilute the researched-script, sourced-visuals, approved-audio, rendered-package path that proves the product works.
