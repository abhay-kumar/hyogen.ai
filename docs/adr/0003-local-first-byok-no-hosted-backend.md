# Local-First BYOK with No Hosted Backend

hyogen.ai's MVP stores projects, assets, credential references, and traces locally, uses the Creator's own provider keys, and ships without a hosted backend, cloud sync, telemetry, or license gate. This is less convenient than SaaS-style onboarding and remote processing, but it matches the trust model for an open-source video tool that handles private creative material, raw provider logs, and local media.
